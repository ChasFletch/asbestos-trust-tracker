# Embeddable Asbestos Trust Fund Clock — Directory Submission

## Canonical URL

`https://asbestostrusts.org/embed/clock`

## Suggested listing title

**Embeddable U.S. Asbestos Trust Fund Clock**

## Suggested description

>An embeddable, source-classified clock showing a documented remaining-assets floor and bottom-up cumulative payouts across U.S. asbestos bankruptcy trusts. The display separates the tracker snapshot from the underlying report dates and links to methodology and source records.

## Suggested attribution

> Powered by [AsbestosTrusts.org](https://asbestostrusts.org/embed/clock), an independent public research tracker supported by Danziger & De Llano, LLP. The display links readers to methodology and per-trust source records.

## Submission notes

The URL is a standalone iframe-ready page. It now returns HTTP 200 and server-renders the current compensation figures, scope qualification, tracker snapshot, and underlying-figure date range for visitors and crawlers. The disclosure is data-driven: it identifies the current documented-asset coverage and distinguishes the tracker refresh date from the reporting years represented in the published rows. Publishers may use the on-site **Embed this clock** control on the homepage to select a compact or full-width iframe snippet.
